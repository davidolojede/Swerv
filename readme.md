# SWERV 👟

SWERV is a modern sneaker e-commerce storefront with a client-facing shopping experience and an admin dashboard for managing products, orders, customers, and inventory.

### Features

* 🛍️ Browse and search sneakers
* 🛒 Cart and checkout
* 👤 User authentication
* 📦 Order management
* 📊 Admin dashboard & analytics
* 👟 Product and inventory management
